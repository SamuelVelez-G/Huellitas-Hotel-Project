01 Proyectos

Huellitas Hotel

Aplicación web para la gestión de un hotel para mascotas, desarrollada en equipo con Java y Spring Boot. El proyecto cuenta con funcionalidades de autenticación y roles, gestión de usuarios y mascotas, administración de servicios y especies, y creación y seguimiento de reservas. El backend utiliza Spring Security, JWT y PostgreSQL para garantizar una gestión segura de la información.
